# Yash — Work Log

A day-by-day record of building an AI agent on **Hyland's Agent Builder Platform**
and connecting it to the local **UCEB MCP Server** so the agent can use its tools.

## How this log works
- Each day gets its own file: `day-01.md`, `day-02.md`, etc.
- "Day" changes only when Yash says so (not by calendar date).
- Each day captures: what we decided, what we learned, what we did, and what's next.

## Project in one sentence
Replace GitHub Copilot as the "host" with a **cloud-hosted Hyland Agent Builder agent**
that talks to the **local UCEB MCP Server** (exposed via a public tunnel), fronted by a
**browser chatbot** so a user can type things like *"capture this file to campaign 701000000000001"*.
