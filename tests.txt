0. BEFORE YOU START (prerequisites)
------------------------------------------------------------------------------
- All 4 processes are running:
    * UCEB API        -> http://localhost:5000
    * MCP server      -> http://localhost:5200  (--http, signed in at warm-up)
    * dev tunnel      -> forwards :5200 (Studio MCP URL points at it)
    * BFF             -> https://localhost:5010
- The MCP server shows "[Warmup] Pre-authentication complete" in its terminal.
  (Warm-up token lasts ~15 min; if tools start failing after a while, restart
   the MCP server and complete the browser sign-in again.)
- In the browser: reload the extension, open the panel, and SIGN IN.
  (A BFF restart clears sessions, so sign in again if chat says unauthorized.)

==============================================================================
TROUBLESHOOTING
==============================================================================
- "Agent call failed (400) ... /invoke": a tool threw server-side. Check the
  MCP server terminal for the "fail:" stack trace; tell me the exact error.
- "unauthorized" / chat won't respond: sign in again in the panel (BFF session
  was cleared, e.g. after a BFF restart).
- Tools hang or time out after ~15 min: MCP warm-up token expired -> restart the
  MCP server and complete the browser sign-in.
- Uploaded file doesn't appear: re-run the list prompt; confirm the doc type and
  record id match what you uploaded to.
